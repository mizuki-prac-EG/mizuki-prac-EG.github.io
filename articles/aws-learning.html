ABOUT

このページについて

AWSには多くのサービスがあり、それぞれ役割や得意分野が異なります。 このページでは、サービスを11分野に分類して整理しています。 分野を選択すると、その分野の役割や利用場面を確認できます。

AWS SERVICE CATEGORIES

分野から探す

キーワードや分野を指定して、知りたいAWSサービスを探せます。

分野名・サービス名・役割などから検索できます。

11分野を表示中

01 / COMPUTE

コンピューティング

主要サービス
  • Amazon EC2
  • AWS Lambda
  • Elastic Beanstalk
  • Amazon ECS
  • Amazon EKS
  • AWS Fargate
  • AWS Batch

この分野の役割

アプリケーションやプログラムを実行するための計算環境を提供します。 仮想サーバーを管理する方法から、サーバー管理を抑えて プログラムやコンテナを実行する方法まであります。

主な利用場面

  • 仮想サーバーを構築する
  • イベントに応じてプログラムを実行する
  • コンテナアプリケーションを動かす
  • バッチ処理を実行する

学習ポイント：サーバー管理の有無、実行方式、拡張性の違い。

02 / STORAGE

ストレージ

主要サービス
  • Amazon S3
  • Amazon EBS
  • Amazon EFS
  • Amazon FSx
  • S3 Glacier
  • Storage Gateway

この分野の役割

ファイル、アプリケーションのデータ、バックアップなどを保存します。 データの種類やアクセス頻度、共有方法、コストに応じて 適切なストレージを選択します。

主な利用場面

  • 画像やログを保存する
  • EC2のディスクを用意する
  • 複数のサーバーでファイルを共有する
  • 長期間アクセスしないデータを保管する

学習ポイント：オブジェクト・ブロック・ファイルの違い。

03 / DATABASE

データベース

主要サービス
  • Amazon RDS
  • Amazon Aurora
  • Amazon DynamoDB
  • Amazon ElastiCache
  • Amazon MemoryDB
  • Amazon Redshift
  • Amazon DocumentDB

この分野の役割

アプリケーションが利用するデータを保存・検索・更新します。 データの構造やアクセス方法、処理速度、可用性などの要件に応じて、 リレーショナルデータベースやNoSQLなどを選択します。

主な利用場面

  • 業務システムのデータを管理する
  • 大量のキー・バリュー型データを扱う
  • 読み込みを高速化する
  • 大量のデータを分析する

学習ポイント：RDS・DynamoDB・ElastiCache・Redshiftの使い分け。

04 / NETWORK

ネットワーク・コンテンツ配信

主要サービス
  • Amazon VPC
  • Elastic Load Balancing
  • Amazon Route 53
  • Amazon CloudFront
  • AWS Direct Connect
  • Site-to-Site VPN
  • Transit Gateway
  • AWS PrivateLink
  • Global Accelerator

この分野の役割

AWS上のネットワークを構築し、リソース同士の通信や インターネットとの接続を管理します。 通信の振り分け、名前解決、拠点間接続なども扱います。

主な利用場面

  • クラウド上にネットワークを構築する
  • 複数のサーバーに通信を振り分ける
  • ドメイン名からサービスに接続する
  • 社内ネットワークとAWSを接続する

学習ポイント：VPC・サブネット・ルートテーブル・DNS・接続方式。

05 / SECURITY

セキュリティ・認証・権限管理

主要サービス
  • AWS IAM
  • IAM Identity Center
  • AWS KMS
  • Secrets Manager
  • AWS Certificate Manager
  • AWS WAF
  • AWS Shield
  • Amazon GuardDuty
  • AWS Security Hub
  • Amazon Cognito

この分野の役割

AWSリソースへのアクセス権限、データの暗号化、 認証情報の保護、脅威の検出などを通じて、 システムやデータの安全性を確保します。

主な利用場面

  • ユーザーごとに操作できる範囲を制限する
  • 保存データを暗号化する
  • パスワードやAPIキーを管理する
  • 不審な操作や攻撃を検知する

学習ポイント：認証と認可、暗号化、アクセス制御、脅威検出。

06 / ANALYTICS

データ分析・データ処理

主要サービス
  • Amazon Athena
  • AWS Glue
  • Amazon Kinesis Data Streams
  • Amazon Data Firehose
  • Amazon EMR
  • Amazon QuickSight
  • AWS Lake Formation
  • AWS Data Exchange

この分野の役割

大量のデータを収集・加工・蓄積・分析し、 意思決定や業務改善に役立つ情報を取り出します。 リアルタイム処理から大規模なデータ分析まで対応します。

主な利用場面

  • S3上のデータをSQLで分析する
  • 複数のデータソースを加工・統合する
  • リアルタイムのイベントデータを処理する
  • 分析結果をダッシュボードで表示する

学習ポイント：データ収集・ETL・データレイク・分析の違い。

07 / INTEGRATION

アプリケーション統合・メッセージング

主要サービス
  • Amazon SQS
  • Amazon SNS
  • Amazon EventBridge
  • AWS Step Functions
  • Amazon MQ

この分野の役割

複数のアプリケーションやAWSサービスを連携させます。 メッセージを介して処理を分離したり、 イベントに応じて処理を実行したりできます。

主な利用場面

  • 処理をキューにためて順次実行する
  • 複数の宛先に通知を送る
  • イベントをきっかけに処理を開始する
  • 複数の処理をワークフローとして組み合わせる

学習ポイント：SQS・SNS・EventBridgeの使い分け。

08 / OPERATIONS

運用・監視・管理

主要サービス
  • Amazon CloudWatch
  • AWS CloudTrail
  • AWS Config
  • AWS Systems Manager
  • AWS Trusted Advisor
  • AWS Health
  • AWS Organizations
  • AWS Control Tower

この分野の役割

AWS環境の状態や操作履歴を確認し、 設定変更の追跡、障害の検知、運用作業の効率化を支援します。 複数アカウントの管理にも利用します。

主な利用場面

  • CPU使用率などを監視する
  • 誰がどの操作を行ったか確認する
  • リソース設定の変更を追跡する
  • 複数のAWSアカウントを管理する

学習ポイント：監視・操作履歴・構成管理の違い。

09 / AUTOMATION

IaC・構築・デプロイ・自動化

主要サービス
  • AWS CloudFormation
  • AWS CDK
  • AWS CodeBuild
  • AWS CodePipeline
  • AWS CodeDeploy
  • Systems Manager Automation

この分野の役割

インフラ構築やアプリケーションのビルド・テスト・デプロイを コードや自動処理で管理します。 手作業を減らし、構築手順の再現性や運用効率を高めます。

主な利用場面

  • 同じインフラ構成を繰り返し作る
  • コードでインフラを管理する
  • テストからリリースまでを自動化する
  • 定型的な運用作業を自動実行する

学習ポイント：IaCとCI/CD、それぞれの役割。

10 / MIGRATION & RECOVERY

移行・転送・災害対策

主要サービス
  • Application Migration Service
  • AWS DMS
  • AWS DataSync
  • AWS Transfer Family
  • AWS Backup
  • Elastic Disaster Recovery

この分野の役割

オンプレミス環境などからAWSへの移行、 データの転送、バックアップ、災害発生時の復旧を支援します。 データやシステムを安全に移行し、障害への備えを整えます。

主な利用場面

  • 既存サーバーをAWSへ移行する
  • データベースを移行・複製する
  • 大量のファイルを転送する
  • 障害時にシステムを復旧できるようにする

学習ポイント：移行・転送・バックアップ・災害復旧の違い。

11 / EDGE & FRONTEND

コンテンツ配信・エッジ・フロントエンド

主要サービス
  • Amazon CloudFront
  • AWS Amplify
  • AWS Global Accelerator
  • AWS Wavelength

この分野の役割

Webコンテンツの配信やフロントエンドアプリケーションの開発を支援し、 ユーザーに近い場所を活用した配信・処理などを実現します。

主な利用場面

  • Webサイトのコンテンツを高速に配信する
  • Webアプリケーションの開発・公開を効率化する
  • グローバルな通信を最適化する
  • 5Gネットワークに近い場所で処理する

学習ポイント：ネットワークとエッジを活用した仕組みの違い。
